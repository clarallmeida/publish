# clarallmeida.com

Clara Almeida's portfolio. Static HTML, CSS and JS — no build step and no
dependencies. Served by GitHub Pages from the root of `main`.

- `CNAME` holds the custom domain. Deleting it unpublishes the domain.
- `.nojekyll` stops GitHub running Jekyll over the files.
- Design tokens (colours, type) live at the top of `styles.css` in `:root`.

To change something: edit the file, commit, push. The live site updates in
about a minute.
